# Honeypot с анализом атак

Семестровая работа. Honeypot на Python + анализ собранных атак.

## Части проекта
- A: сенсоры (sensors, shell) - сбор данных
- B: аналитика (enrich, analysis, dashboard) - анализ данных
- общее: events, logger, storage

## Запуск
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
